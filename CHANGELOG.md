# История изменений

## Статистика качества подключения — 2026-10-10

- Приложение может анонимно сообщать об обрывах и ошибках подключения, чтобы мы быстрее находили проблемные серверы и сети. IP-адреса, сайты и данные аккаунта не отправляются; при первом запуске приложение спрашивает согласие, отключить можно в настройках.
- Проверка туннеля различает причины сбоя: таймаут, ошибку TLS, сброс соединения, ответ прокси.
- Журнал диагностики сохраняется на диск с удалением IP-адресов, доменов и идентификаторов.

## Стабильность на компьютерах без IPv6 — 2026-10-09

- Исправили зацикливание соединений на компьютерах, где у сетевого адаптера выключен IPv6: со временем оно приводило к обрыву интернета через VPN.
- Если у сетевого адаптера нет IPv6, туннель работает только по IPv4.

## Исправление TUIC — 2026-10-09

- Исправили открытие сайтов в браузере при подключении через TUIC: DNS и QUIC теперь проходят через туннель.

## 1.3.0 — 2026-10-09

- Добавили дополнительный способ подключения к серверам.
- Теперь способ подключения можно выбрать прямо в карточке сервера.
- Улучшили работу с обновлёнными настройками серверов в сетях с ограничениями.

## Подключение при недоступных сетевых классах WMI — 2026-10-01

- Определение сетевого интерфейса использует Windows IP Helper API напрямую, без PowerShell и WMI. Ошибка Windows «Недопустимый класс» (`0x80041010`) больше не блокирует этот этап подключения, если системные маршруты и физический адаптер доступны.
- Сохранены выбор по метрикам IPv4/IPv6, исключение виртуальных VPN-адаптеров и прежние резервные запросы.
- Добавлены регрессионные проверки отсутствующих WMI-классов и проверка нативного запроса и его JSON в Windows-сборке.

## Определение сетевого интерфейса Windows — 2026-10-01

- При сбое, таймауте или пустом ответе NetTCPIP приложение определяет физический адаптер с подключённым шлюзом резервным способом через Win32.
- Увеличено время ожидания ответа Windows и добавлены скрытые сетевые адаптеры при чтении активных маршрутов.
- Журнал показывает причину сбоя каждого способа и состояние адаптеров, чтобы отличать конфликт VPN от ошибки служб Windows или отсутствия подключения.
- Добавлены проверки резервного определения интерфейса и исполнения обоих PowerShell-запросов в Windows CI.

## Стабильность Windows — 2026-09-27

- Kill Switch сохраняет служебный DHCP/NDP-трафик для восстановления сети и проверяет полный набор своих обязательных фильтров.
- Исправлены гонки отключения и восстановления защиты; неудачная попытка восстановления больше не выключает дальнейший контроль.
- Исходная DNS-политика сохраняется до изменения и восстанавливается после перезапуска приложения; ошибки восстановления можно повторить без потери резервной копии.
- Остановка Xray ожидает фактического завершения процесса; убраны отложенные принудительные остановки уже завершённых процессов и устаревшие результаты статистики.
- Проверка конфигурации ядра имеет таймаут. При запуске проверка передачи трафика повторяется один раз без пересоздания туннеля.
- После неудачной смены сервера можно выбрать другой и сразу переподключиться, сохранив Kill Switch.
- Отключение доступно из трея при подключении, восстановлении и ошибке. Приложение сообщает об ошибке очистки сети перед выходом.
- Уведомления больше не показывают технический префикс Electron IPC; некорректный IPv4 DNS отклоняется до изменения соединения.

## 1.2.4

- Включён Mux для альтернативного VLESS XHTTP/SplitHTTP сервера, чтобы использовать серверные keepalive и повысить стабильность соединения.
- Сохранён приоритет настроек Mux из профиля и совместимость с Anti-DPI; добавлены регрессионные проверки.

## Следующий релиз

- Исправлена блокировка локальной связи Battle.net с Agent.exe при включённом Kill Switch; исключение Overwatch сохраняет прямое подключение игры.

- Исправлена читаемость списка серверов на главном экране во всех темах.
- Добавлены вращающееся кольцо и пульсация при подключении, восстановлении и отключении VPN с учётом настройки уменьшения анимации.
- Исправлено восстановление доступа к сети после перезагрузки Windows.
- Приложение сохраняет локальную сессию при временном отсутствии интернета.
- Повышена надёжность защиты соединения при подключении и восстановлении VPN.
- Улучшено безопасное взаимодействие приложения с системными компонентами Windows.
- Добавлены дополнительные автоматические проверки критичных сценариев работы.
