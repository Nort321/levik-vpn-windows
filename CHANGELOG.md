# История изменений

## 1.2.4

- Включён Mux для альтернативного VLESS XHTTP/SplitHTTP сервера, чтобы использовать серверные keepalive и повысить стабильность соединения.
- Сохранён приоритет настроек Mux из профиля и совместимость с Anti-DPI; добавлены регрессионные проверки.

## Следующий релиз

- Исправлена блокировка локальной связи Battle.net с Agent.exe при включённом Kill Switch; исключение Overwatch сохраняет прямое подключение игры.

- Исправлена читаемость списка серверов на главном экране во всех темах.
- Добавлены вращающееся кольцо и пульсация при подключении, восстановлении и отключении VPN с учётом настройки уменьшения анимации.
- Исправлено восстановление доступа к сети после перезагрузки Windows.
- Приложение сохраняет локальную сессию при временном отсутствии интернета.
- Повышена надёжность защиты соединения при подключении и восстановлении VPN.
- Улучшено безопасное взаимодействие приложения с системными компонентами Windows.
- Добавлены дополнительные автоматические проверки критичных сценариев работы.
